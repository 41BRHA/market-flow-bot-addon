Trade dates and disclosure dates are different. Reported amounts are ranges, not exact position sizes. The estimated value is the midpoint of a bounded range; an open-ended range uses its disclosed minimum. Market prices are estimates from Market Flow: the daily close on the trade date (or next session), not the politician's execution price.

Score method, value estimates, sources, coverage and import

Trade Score (0–100): 50 is neutral. Each Buy is positive when the market price has risen since the estimated trade-date close; each Sell is positive when it has fallen. The score combines equal-weight average direction-adjusted return and win rate, caps extreme returns at ±50%, and shrinks small samples toward 50 using n/(n+5). The underlying win rate, average return and rated sample are shown in every expanded disclosure.

Estimated values: a bounded reported range uses its midpoint. Filing estimates sum those transaction estimates. If a range is open-ended, its minimum is used and marked “at least”; missing ranges are marked incomplete. These are comparison aids, not exact transaction or current position values.

House: official Clerk annual PTR index and transaction PDFs. Only explicit ticker matches are included; scanned reports and unsupported layouts are flagged. Senate: optional Financial Modeling Prep API key with endpoint access, or import a CSV. A Senate subscription is not included. Coverage is partial and these records do not establish current holdings.
